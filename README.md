# MD Live Editor

Markdownの記法を打つと、その場でスタイルが反映される「ライブ編集」型のMarkdownエディタです。Notionのようにフォルダの中のファイルをツリーから選んで開き、ローカルのファイルを直接上書き保存します。HTML/CSS/JSのみで動く単一ファイルのアプリです。

## 使い方

1. `md-live-editor.html` をブラウザ(Chrome / Edge 推奨)で開く
2. ヘッダーの「📁 フォルダを開く」をクリックし、編集したいMarkdownファイルが入ったフォルダを選択
3. 左のサイドバーに表示されるファイルツリーから、開きたい `.md` ファイルをクリック
4. 編集すると装飾がそのまま反映される。保存は `Cmd/Ctrl + S`

> ファイルを開くまではエディタには何も入力できません(このアプリは「フォルダを開いて初めて使える」設計です)。

## 動作環境について

- ファイルの上書き保存・フォルダの読み込みには **File System Access API** というブラウザ機能を使っています。対応しているのは Chrome / Edge などの Chromium系ブラウザのみです。
- Safari / Firefox など非対応ブラウザでは、フォルダを開く機能自体が使えません。

## Markdownの記法(入力すると自動で装飾される)

| 入力 | 結果 |
|---|---|
| `# ` `## ` `### ` | 見出し1〜3 |
| `- ` または `* ` | 箇条書き |
| `1. ` | 番号付きリスト |
| `- [ ] ` | チェックボックス(クリックでON/OFF切り替え) |
| `> ` | 引用 |
| `---` + Enter | 区切り線 |
| ` ``` ` + Enter | コードブロック開始 |
| `**太字**` | **太字** |
| `*斜体*` または `_斜体_` | *斜体* |
| `` `コード` `` | インラインコード |
| `[表示テキスト](リンク先)` | リンク |
| `\| セル \| セル \|` | テーブル(下記スニペット推奨) |

## スニペット(`/`コマンド)

行の先頭で `/` を打つとメニューが出て、次の要素を挿入できます。

- `/table` … 3×2 のテーブル
- `/border` … 区切り線
- `/checkbox` … チェックボックス
- `/link` … リンク(挿入直後に編集ツールバーが開き、表示テキストとリンク先を入力できる)

## キーボード操作

| キー | 動作 |
|---|---|
| `Enter` | 新しい行を作成(リスト・引用・チェックボックスは同じ種類のまま続く) |
| `Enter`(空の行で) | 元の段落に戻る |
| `Backspace`(コードブロックの最後の空行で) | コードブロックを抜ける |
| `Tab` / `Shift+Tab` | インデントを増減(最大6段階) |
| `Tab` / `Shift+Tab`(テーブル内) | 隣のセルへ移動。最後のセルで`Tab`は新しい行を追加 |
| `Shift+Enter`(テーブルのセル内) | 行を追加せず、セル内で改行 |
| `Cmd/Ctrl + S` | 保存(開いているファイルを直接上書き) |
| `Cmd/Ctrl + Z` | 元に戻す |
| `Cmd/Ctrl + Shift + Z` | やり直す |

## リンクの編集

- リンクにキャレットを合わせると、小さな「✎ 編集」ボタンが表示される
- クリックすると、リンク先(URL / ファイルパス)と表示テキストを入力できる編集ツールバーが開く
- リンクを**左クリック**するとそのままリンク先に移動する(他の `.md` ファイルへの相対パスも解決される)

## テーブルの編集

- テーブルにキャレットを合わせると、右上あたりに列の追加(列+)・削除(列−)ボタンが出る
- 行の追加は、最終行で `Enter` または `Tab`
- セル内での改行は `Shift+Enter`(保存したMarkdownには `<br>` として書き出され、再度開いたときも復元される)

## ファイル操作(サイドバー)

- 📁 フォルダを開く … 編集対象のフォルダを選択
- ＋ / 📁+ … 新しいファイル / フォルダを作成
- 各ファイル・フォルダ … クリックで名前変更、🗑 で削除
- 🔄 更新(ヘッダー) … 開いているファイルの最新の内容をディスクから読み直す(未保存の編集内容は破棄される)

## 目次(アウトライン)

ヘッダーの「📑 目次」から、文書内の見出し(`#`〜`###`)一覧を開ける。クリックでその行へジャンプする。ファイルを開き直す・更新すると目次の内容も自動で更新される。

## 制限事項

- ブラウザの仕様上、ファイルの**絶対パス**は取得できないため、表示されるのはファイル名のみ
- 上書き保存・自動更新は File System Access API に対応したブラウザでのみ動作(非対応の場合はダウンロードにフォールバック)
- 複数人での同時編集には対応していない
